Diferenças de regex entre Python, JavaScript e Rust

O que muda de uma linguagem para outra, testado na prática, para seu padrão não quebrar quando trocar de ambiente.

Por que o mesmo regex muda de linguagem para linguagem

Cada linguagem tem seu motor de regex, chamado de sabor. A base é a mesma, mas recursos avançados e o tratamento de acentos mudam. É por isso que um padrão testado em Python pode dar erro no JavaScript ou no AutoMod do Discord, que usa Rust.

Conferido rodando cada exemplo em Python 3.13, Node.js 22 e na biblioteca regex do Rust 1.13.

Como usar no código

Python

import re

texto = "CEP 50740-560"
achou = re.search(r"\d{5}-?\d{3}", texto)
print(achou.group())  # 50740-560

JavaScript

const texto = "CEP 50740-560";
const achou = texto.match(/\d{5}-?\d{3}/);
console.log(achou[0]); // 50740-560

No Python, use string com r na frente (r"...") para a barra invertida não ser interpretada duas vezes.
