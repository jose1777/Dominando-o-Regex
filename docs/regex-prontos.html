Regex prontos para os formatos brasileiros

Padrões para copiar e usar, com explicação e um testador para conferir no seu texto antes de colocar no código.

Regex para CPF

Aceita CPF com ou sem pontuação, como 123.456.789-09 e 12345678909.

\d{3}\.?\d{3}\.?\d{3}-?\d{2}

Confere só o formato. Para saber se o CPF é válido é preciso calcular os dígitos verificadores no código.

Regex para CNPJ

Aceita CNPJ formatado como 12.345.678/0001-95 ou só com números.

\d{2}\.?\d{3}\.?\d{3}/?\d{4}-?\d{2}

Assim como no CPF, a validação real depende dos dígitos verificadores.

Regex para CEP

Aceita CEP com ou sem hífen, como 50740-560 e 50740560.

\b\d{5}-?\d{3}\b

Regex para celular brasileiro

Aceita celular com DDD em vários formatos, como (81) 99999-1234, 81 99999-1234 e 81999991234.

\(?\d{2}\)?\s?9\d{4}-?\d{4}

O 9 depois do DDD separa celular de telefone fixo.

Regex para email

Encontra endereços de email comuns, como nome.sobrenome@empresa.com.br.

[A-Za-z0-9._%+-]+@[A-Za-z0-9.-]+\.[A-Za-z]{2,}

Nenhum regex cobre 100% dos emails válidos. Para cadastro, o jeito seguro é enviar um email de confirmação.

Regex para data dd/mm/aaaa

Encontra datas no formato brasileiro e já rejeita dia 32 e mês 13.

\b(0[1-9]|[12]\d|3[01])/(0[1-9]|1[0-2])/\d{4}\b

Ainda aceita 31/02. Para checar o calendário de verdade, converta a data no código.

Regex para link HTTP e HTTPS

Encontra links que começam com http ou https.

\bhttps?://\S+

Regex para placa de carro

Aceita placa no padrão antigo (ABC-1234) e no padrão Mercosul (ABC1D23).

\b[A-Z]{3}-?\d[A-Z0-9]\d{2}\b

Regex para hashtag

Encontra hashtags em textos de redes sociais.

#\w+
